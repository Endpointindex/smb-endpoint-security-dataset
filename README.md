# SMB Endpoint Security Dataset

Maintained by [Endpoint Index](https://endpointindex.com), an independent database of endpoint security products for small and mid-sized businesses.

## What this is

A structured, source-linked reference of endpoint protection, EDR and related products, focused on what matters to SMB buyers: deployment model, management, pricing signals, and independent test evidence.

Every entry links back to its public profile on endpointindex.com, where sources and update dates are shown.

The full, current data lives on endpointindex.com; this repository documents the schema and methodology.

## Fields

| Field | Description |
|---|---|
| vendor | Company that makes the product |
| product | Product name |
| category | EPP, EDR, MDR, XDR or similar |
| smb_fit | Whether the product is suited to small and mid-sized teams |
| deployment | Cloud, on-premise or hybrid |
| pricing_model | Public pricing model, where disclosed |
| independent_tests | Third-party lab results referenced, where available |
| profile_url | The product's page on endpointindex.com |
| last_reviewed | Date the entry was last checked |

## Methodology

Entries are compiled from vendor documentation, public pricing pages and independent test labs. Endpoint Index does not accept payment for rankings. See the editorial policy at https://endpointindex.com.

## Updates and corrections

Vendors can request inclusion or corrections at https://endpointindex.com or by emailing contact@endpointindex.com.
